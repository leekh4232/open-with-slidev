Open with Slidev

마크다운 파일을 우클릭 한 번으로 Slidev 슬라이드로.
터미널도, 설치도, 테마 준비도 익스텐션이 대신합니다.

VS Code Marketplace에서 설치 테마 매뉴얼

하는 일

  • 🖱️
    우클릭 한 번으로 실행

    편집기 · 탭 · 탐색기의 md 파일에서 바로 슬라이드 서버를 띄웁니다.

  • 📦
    설치 없이 동작

    프로젝트에 Slidev가 없어도 필요한 것을 내려받아 실행합니다.

  • 🎨
    테마 34종

    전용 테마 jussam · hossam과 공식 · 갤러리 테마를 이름만으로 씁니다.

  • 🪟
    미리보기 위치 선택

    외부 브라우저나 VS Code 안 탭에서 슬라이드를 봅니다.

  • 🔌
    덱 여러 개 동시에

    빈 포트를 알아서 찾아, 파일마다 서버를 따로 띄웁니다.

  • 🎤
    발표자 모드

    원하면 발표자 화면도 함께 엽니다.

시작하기

ext install leekh.open-with-slidev
  1. md 파일 맨 위에 테마를 적습니다. 적지 않으면 jussam이 쓰입니다.
  2. 파일을 우클릭하고 Open with Slidev를 고릅니다.
  3. 서버가 뜨면 브라우저에 슬라이드가 열립니다.
---
theme: jussam        # 또는 hossam, seriph, terminal …
title: 발표 제목
---
