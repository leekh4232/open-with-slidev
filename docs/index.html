빠른 시작

  1. VS Code에서 Open with Slidev를 설치합니다. Node.js 18 이상이면 되고, 프로젝트에 Slidev를 설치할 필요는 없습니다.
  2. 슬라이드 md 파일 맨 위 프런트매터에 테마 이름을 적습니다. 적지 않으면 설정 openWithSlidev.defaultTheme(기본 jussam)이 쓰입니다.
  3. 편집기나 탐색기에서 md 파일을 우클릭 → Open with Slidev. 명령 팔레트의 Slidev: Open with Slidev로도 됩니다.
---
theme: jussam        # 또는 hossam
title: 발표 제목
---

# 첫 슬라이드

Slidev 자체의 문법(슬라이드 구분 ---, 클릭 애니메이션 v-click, 코드 하이라이트 등)은 그대로 쓸 수 있습니다. 자세한 내용은 sli.dev를 보세요.

전체 예제 덱

  • jussam-example.md — 분기 개발 생산성 리뷰(가상 수치). 레이아웃 3종과 컴포넌트 전부를 한 번씩 씁니다.
  • hossam-example.md — 파이썬 기초 3강. 콜아웃·프롬프트·출력·단계 목록과 사이드바.

내려받아 아무 폴더에 두고 우클릭 → Open with Slidev 하면 바로 열립니다. 익스텐션 없이 보려면 저장소의 themes/<이름> 폴더를 복사한 뒤 npx @slidev/cli 파일.md --theme ./jussam 처럼 실행합니다.
