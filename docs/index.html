Open with Slidev

마크다운 파일을 우클릭 한 번으로 Slidev 슬라이드로.
터미널도, 설치도, 테마 준비도 익스텐션이 대신합니다.

VS Code Marketplace에서 설치 GitHub

하는 일

  • 🖱️
    우클릭 한 번으로 실행

    편집기 · 탭 · 탐색기의 md 파일에서 바로 슬라이드 서버를 띄웁니다.

  • 📦
    설치 없이 시작

    프로젝트에 Slidev가 없으면 처음 한 번 그 폴더에 설치하고 바로 띄웁니다.

  • 🎨
    테마 32종 · 폴더 테마

    공식 · 갤러리 테마는 이름만으로, 직접 받은 테마는 폴더 경로로 씁니다.

  • 🪟
    미리보기 · 발표자 모드

    외부 브라우저나 VS Code 안 탭에서 보고, 원하면 발표자 화면도 함께 엽니다.

  • 🔌
    덱 여러 개 동시에

    빈 포트를 알아서 찾아, 파일마다 서버를 따로 띄웁니다.

  • 📄
    HTML · PDF · PPTX로 내보내기

    Build with Slidev 하위 메뉴로 서버 없이 열리는 HTML 한 파일, PDF, PPTX, PNG, Markdown을 만듭니다.

hossam 테마

코딩 강의용 테마 hossam은 Slidev Themes 저장소에 있습니다. 저장소를 받아 theme: ./slidev-themes/hossam처럼 경로로 적습니다.

hossam 테마 강의흰 바탕 코딩 강의용. 왼쪽 목차 사이드바, 콜아웃 · 프롬프트 · 출력 상자.사용법 보기 → 예제 덱 lecture-example.md파이썬 기초 3강. 콜아웃 · 프롬프트 · 출력 · 단계 목록과 사이드바.예제 보기 →

시작하기

ext install leekh.open-with-slidev
  1. md 파일 맨 위에 테마 이름이나 테마 폴더 경로를 적습니다.
  2. 파일을 우클릭하고 Open with Slidev를 고릅니다.
  3. 서버가 뜨면 브라우저에 슬라이드가 열립니다.
---
theme: ./slidev-themes/hossam   # 또는 seriph, terminal …
title: 발표 제목
---
